# EGS Companion

The official Windows app for [EveryGameStat](https://everygamestat.com). It measures your game sessions on your own PC and puts them on your EGS card: Rocket League matches, playtime for every game, Minecraft hours per server, and Discord presence.

## Download

**[Download EGS-Companion-Setup.exe](https://github.com/Geaardheid/egs-companion/releases/latest/download/EGS-Companion-Setup.exe)** (Windows 10/11, free)

Or get it from [everygamestat.com/companion](https://everygamestat.com/companion). After installing, the app updates itself.

## How it stays safe

- **Read-only.** It only reads local log files and the local APIs games expose on purpose.
- **Never game memory.** It does not attach to, inject into, or read the memory of any game process.
- **No passwords.** Linking uses a one-time code from the site; you can revoke the device any time.
